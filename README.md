# 长城外卖销量统计 · 程序更新

本仓库仅用于发布软件安装包及完整性校验文件。不包含商品档案、订单、登录账号、密码或浏览器资料。

## 下载

[打开最新版下载页](https://github.com/buxiaobu666-ship-it/ccmarket-delivery-updates/releases/latest)

- Windows 64位：选择文件名含 `win-x64.zip` 的文件。
- Mac Apple芯片：选择文件名含 `mac-arm64.zip` 的文件。此包不适用于Intel Mac。

## 更新步骤

1. 软件0.2.1起已内置正式更新地址，启动时自动检查，也可点击“软件更新”。
2. 点击“下载新版”，软件选择本机安装包并校验SHA256。
3. 下载完成后结束统计、退出旧程序。Windows解压整个新版文件夹并运行其中exe；Mac解压并替换.app。
4. 不要删除“本地数据目录”，原有本机订单及匹配记忆会保留。更新不会在两台电脑之间自动同步业务资料。

0.2.0用户：在“软件更新”的发布地址填写 `buxiaobu666-ship-it/ccmarket-delivery-updates`，点击保存后检查更新。更早没有更新入口的版本，需要先安装最新版一次。

目前为检查、提醒和确认下载，不是后台静默安装。首次启动可能受系统安全策略影响，程序尚未购买代码签名证书；请遵循系统或组织策略，不要关闭防护或绕过管理限制。

## 数据与口径

商品档案和订单仅保存在使用者电脑中。统计数量仍按平台售卖单位，不自动把箱换算为瓶；录入ERP前请核对单位及待匹配商品。
